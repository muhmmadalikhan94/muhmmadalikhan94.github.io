ABT|About

Systems that talk to each other, cleanly.

I'm a Computer Science undergraduate at Air University who has already shipped integration code in a real healthcare setting.

Most of my work sits where systems meet: REST APIs, webhooks, JSON and XML payloads, and the parsing logic that turns a pipe-delimited HL7 message into data another service can trust. On the side I build things I want to use, from a RAG assistant that answers questions about long PDFs to an F1 companion app with live timing.

I work mainly in Python, C# and Flutter, and I like Agile teams where testing is part of the job, not an afterthought.
